# Lab 31: Visualizing Intermediate Activations

## 1. Introduction

In this lab, I learned how to visualize intermediate activations in a Convolutional Neural Network (CNN) using a pretrained VGG16 model.

Intermediate activations are the outputs produced by different layers of a neural network while processing an image.

They help us understand what features a model detects at different stages.

For example:
- Early layers detect edges, colors, and simple patterns.
- Middle layers detect more complex shapes and textures.
- Deeper layers combine features to understand more complex patterns.

## 2. Objectives

- Understand intermediate activations in neural networks.
- Extract feature maps from different convolutional layers.
- Visualize convolutional feature maps.
- Analyze how image features change across network layers.
- Understand the role of pooling layers and activation functions.

## 7. Task 2: Extract Intermediate Activations

### Explanation

In this task, I extracted the outputs of the first eight layers of VGG16.

I used the Keras `Model` class to create an activation model.

This model returns the outputs of selected layers instead of only the final output.

### Important Code Concepts

**model.layers[:8]**

Selects the first eight layers of the VGG16 model.

**layer.output**

Provides the output tensor of a selected layer.

**activation_model.predict()**

Runs the input image through the activation model and returns intermediate outputs.

### Activation Output Shapes

```text
final feature map: (1, 7, 7, 512)

input_layer (1, 224, 224, 3)
block1_conv1 (1, 224, 224, 64)
block1_conv2 (1, 224, 224, 64)
block1_pool (1, 112, 112, 64)
block2_conv1 (1, 112, 112, 128)
block2_conv2 (1, 112, 112, 128)
block2_pool (1, 56, 56, 128)
block3_conv1 (1, 56, 56, 256)
```

### Understanding Layer Changes

| Layer | Feature Map Shape |
|---|---|
| input_layer | 224 × 224 × 3 |
| block1_conv1 | 224 × 224 × 64 |
| block1_conv2 | 224 × 224 × 64 |
| block1_pool | 112 × 112 × 64 |
| block2_conv1 | 112 × 112 × 128 |
| block2_conv2 | 112 × 112 × 128 |
| block2_pool | 56 × 56 × 128 |
| block3_conv1 | 56 × 56 × 256 |

### Important Observation

Convolutional layers extract features from the image, while pooling layers reduce the spatial dimensions of feature maps.

As the network becomes deeper, the number of feature channels increases.

## 8. Task 3: Visualize Intermediate Activations

### Explanation

In this task, I visualized the activation maps produced by different VGG16 layers.

I used Matplotlib with the `Agg` backend because the lab environment does not require a graphical display.

I selected channel 0 from the first convolutional layer and saved it as `first_layer.png`.

I also created a combined visualization of channel 0 from seven intermediate layers and saved it as `activations.png`.

### Generated Visualization Files

**1. first_layer.png**

Shows channel 0 from the first convolutional layer (`block1_conv1`).

**2. activations.png**

Shows channel 0 from seven intermediate layers in a 1 × 7 layout.

The figure dimensions are 2000 × 400 pixels.

### Activation Statistics

The following statistics were calculated for channel 0 of each selected layer.

| Layer | Minimum | Maximum | Mean |
|---|---:|---:|---:|
| block1_conv1 | 0.0 | 615.5 | 6.5 |
| block1_conv2 | 0.0 | 1576.7 | 41.0 |
| block1_pool | 0.0 | 1576.7 | 54.2 |
| block2_conv1 | 0.0 | 370.3 | 37.9 |
| block2_conv2 | 0.0 | 6873.6 | 249.6 |
| block2_pool | 0.0 | 6873.6 | 295.4 |
| block3_conv1 | 0.0 | 6441.2 | 333.5 |

### Understanding Activation Statistics

- Minimum: The smallest activation value in the selected feature map.
- Maximum: The largest activation value.
- Mean: The average activation value.

The activation values change from layer to layer because each layer learns and detects different image features.

The minimum values of zero are consistent with ReLU activation, which removes negative values.

## 9. Important Concepts Learned

### Convolutional Neural Network (CNN)

A CNN is a deep learning model commonly used for image processing and computer vision.

### Intermediate Activations

Intermediate activations are outputs produced by hidden layers of a neural network.

### Feature Maps

Feature maps represent patterns detected by convolutional filters.

### Pooling

Pooling reduces the spatial size of feature maps while retaining important information.

### ReLU Activation

ReLU stands for Rectified Linear Unit.

It converts negative values to zero while keeping positive values.

### VGG16

VGG16 is a pretrained convolutional neural network architecture that can extract image features using its convolutional layers.
