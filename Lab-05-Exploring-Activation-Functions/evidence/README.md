# Lab 05 - Evidence

## Purpose

This folder contains the evidence collected during the
Exploring Activation Functions practical.

## Evidence Files

### 1. training-results.txt

Contains the training results of three neural network
models using different activation functions:

- ReLU
- Sigmoid
- Tanh

The file includes:
- Initial training loss
- Final training loss
- Loss at epoch 5
- Lowest final loss

### 2. ../loss.png
This graph is saved in the main Lab 05 folder.
It visually compares the training loss of ReLU,
Sigmoid, and Tanh over 30 epochs.

## Experimental Observation

Tanh achieved the lowest final training loss in the
recorded experiment:

- ReLU: 2.3620
- Sigmoid: 3.2848
- Tanh: 2.3355

## Conclusion

The experiment demonstrated how different activation
functions affect neural network training behavior.

Tanh performed best based on the lowest final training
loss in this particular experiment.
